## Findings and remediation

The first full major-gate run found zero confirmed violations and 495 serious incomplete candidates, so it correctly exited inconclusive. The candidates reduced to four shared rendering conditions:

- 147 arrow-only back-to-top controls whose visible content axe could not measure as text.
- 72 breadcrumb links whose contrast could not be determined because they relied on color and overlapped adjacent content.
- 56 one-character matrix links that were too short for axe to classify as text.
- 220 timeline text candidates whose backgrounds could not be determined because decorative lines and markers were pseudo-elements.

The source remediation gives the back-to-top control visible text, restores breadcrumb underlines, gives matrix links descriptive visible labels, provides an accessible dark-mode matrix background, and renders timeline decorations as real `aria-hidden` elements. `npm run build` regenerated the managed public tree. No axe rule, required route, finding class, or evidence type was suppressed.

An intermediate run exposed 56 confirmed serious matrix contrast failures after the one-character labels became measurable, while the 220 timeline candidates remained incomplete. The dark-mode matrix background and remaining timeline pseudo-element were then corrected in source.
