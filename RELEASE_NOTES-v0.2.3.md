# PubLedge v0.2.3

Improves MCP discovery guidance for bundled snapshot, provenance, reliance, and currentness boundaries. `initialize` and `server/discover` now expose the same instructions while retaining the existing 13-tool contract.

Corrects the ElizaChat demonstration remap against the signed agreement. Immediate cure-incident reporting remains separate from 24-hour harm reporting, Phase One commences before the written-approval gate for subsequent phases, and the good-faith cure qualifications are retained. A neutral source-review receipt and focused regression gate preserve those distinctions.

Adds a bounded manual source-maintenance collector with a durable review queue, fail-closed recovery behavior, and tests that keep inaccessible sources and unresolved findings explicit. Collection success does not renew record dates or legal status.

Pins the major accessibility gate by commit and includes the shared rendering fixes validated across all 160 generated HTML routes. The retained audit records zero confirmed violations, incomplete candidates, or route errors in that automated scope, plus representative checks for the affected explicit light and dark themes.

The protocol remains v0.2.0 and the Obligation-First record contract remains v0.6.
